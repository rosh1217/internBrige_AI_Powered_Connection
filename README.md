# 🌉 InternBridge

### AI-Powered Internship & Career Matching Platform
**“Don’t Search. Get Matched.”**

InternBridge is an AI-powered platform that helps students find suitable internships based on their **skills, interests, career goals, and experience**, while identifying skill gaps and providing personalized career guidance.

## ✨ Key Features
- 🎯 AI Internship Matching & Match Score
- 🧠 Skill Gap Analysis
- 🛣️ Personalized Career Roadmap
- 🤖 AI Career Coach
- 📄 AI Resume/ATS Analysis
- 📋 Internship Application Tracker
- 🏢 Recruiter & Candidate Matching
- 🔔 Personalized Opportunity Alerts
- 📱 Responsive, modern UI with animations

## 🛠️ Tech Stack
**Frontend:** HTML, CSS, JavaScript, GSAP/AOS  
**Backend:** Java, Spring Boot, REST API  
**Database:** H2 / PostgreSQL
